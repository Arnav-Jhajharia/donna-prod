Overview

A sub-processor is an external party that processes personal data on donna's behalf to deliver part of the Service. Each provider below operates under a written data processing agreement (or equivalent terms) that restricts use of personal data to processing on donna's documented instructions, requires appropriate security, and supports cross-border transfer where applicable.

"Core" providers are used for every account by default. "Optional" providers are engaged only when you opt in (for example, by connecting an OAuth integration or selecting a voice provider). "Surface" providers run the messaging channel you use to talk to donna.

Updates to this list

We update this page when we add, replace, or remove a sub-processor. For users with an email address on file, we send notice of material additions at least 14 days before the new sub-processor begins processing personal data, except in cases of urgency (e.g., a security-driven replacement), where we will notify you as soon as practicable. To object to a new sub-processor, contact privacy@donna.app; if we cannot accommodate the objection, you may terminate your account and receive any pro-rated refund due under the Terms.
